# SecureFile final scanner, move and pricing update — 2026-08-21

- Basic: $10/month, 1 included user, 5 GB; +$5 per additional user/month.
- Advanced: $15/month, 1 included user, 2 GB; +$10 per additional user/month. Includes Preview, Scanner, Re-sharing and Rename.
- Premium: $25/month, 1 included user, 2 GB; +$12 per additional user/month. Includes all SecureFile features.
- Additional users inherit the selected package entitlements.
- Company Admin can request more users/storage from Settings. Capacity changes only after payment confirmation/webhook.
- Files and folders can be moved from Files using destination-folder controls; personal folders cannot be moved.
- Physical Windows WIA scans are returned page-by-page for review; unwanted pages can be removed before the selected pages are saved as one PDF.
- Mobile scanning uses the phone camera (capture=environment), supports multiple pages, page removal/review, PDF naming and saving into the Scan Documents area.
