# SecureFile Package Pricing Update — 20 Aug 2026

## Packages

- **Basic:** $10/month, 1 included user, 5 GB included, core workspace.
- **Advanced:** $20/month, 5 included users, 2 GB included, File Side-panel Preview, Scanner, File/Folder Re-sharing, User File Rename.
- **Premium:** $25/month, 5 included users, 2 GB included, all available add-ons: Preview, Scanner, Fax, File/Folder Re-sharing, User File Rename, Post-office Mailing.
- **Enterprise:** custom pricing.

## Additional users

For every fixed package, customers can increase the total user count during pricing/signup. Each user above the package's included-user allowance costs **$5/user/month** and retains the package's feature set.

Examples:
- Basic + 1 additional user = $15/month.
- Advanced + 1 additional user = $25/month.
- Premium + 1 additional user = $30/month.

For Enterprise/custom pricing, the existing transparent model remains: $10 for the first user/month, $5 per additional user/month, $0.30/GB/month storage, plus selected add-ons per user/month.
