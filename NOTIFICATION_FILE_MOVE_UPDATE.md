# SecureFile — Notifications, File Actions & Move Update

## Pricing
- Basic: $10/month, 1 included user, +$5/additional user/month, 5 GB included.
- Advanced: $15/month, 1 included user, +$10/additional user/month, 2 GB included.
- Premium: $25/month, 1 included user, +$12/additional user/month, 2 GB included.
- Enterprise: custom pricing.
- Additional users keep the exact feature entitlement of the selected package.

## Notifications
- Added an authenticated Server-Sent Events notification stream for near-real-time delivery.
- Existing polling remains as a fallback.
- Notifications cover relevant workspace events including uploads, folder creation, move/rename/delete/restore, sharing, requests/approvals, tasks, chat/group messages, email, user invitations, subscription/payment events and task reminders.

## File actions
- Clicking a file name no longer downloads it.
- Download happens only from the Download action button.
- Preview/Open happens only from the Preview/Open action buttons when the package entitlement allows it.

## Move
- Files and folders now have a Move action.
- A destination-folder dialog is provided.
- Server-side access checks are enforced.
- Folder cycles are blocked.
- Moving a file/folder generates relevant notifications.

## Subscription increases
- Company Admin can request more users and/or storage from Settings.
- The requested increase is not applied immediately.
- New entitlements become active only after payment approval/webhook confirmation.
